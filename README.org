* My Dotfiles

** Approach and Philosophy

Welcome to my personal dotfiles repository!

While the core of my system configuration is declaratively managed using [[https://nixos.org/][NixOS]], this repository houses the configurations I tend to tweak and iterate on more frequently. Maintaining these dotfiles separately allows for rapid experimentation and on-the-fly adjustments without the need for a full system rebuild via Nix.

Previously, I explored managing these user-level configurations directly within my NixOS setup, including attempts at symlinking. However, these earlier approaches proved less reliable than desired for frequently modified files, sometimes leading to unexpected issues. I've since adopted a more robust separation of concerns:
- *GNU Stow*: Used here to manage the symlinking of these user-level configuration files into the home directory. It excels at this task.
- *NixOS*: Continues to manage the underlying system packages, services, stable configuration, and secrets securely.

This separation provides a balance between NixOS's declarative power for the system foundation and the flexibility needed for evolving user-level preferences.

** My Digital Toolbox

Here's a glimpse into some of the key tools configured within this repository:

- *Emacs*: My primary editor, valued especially for its unparalleled [[https://orgmode.org/][Org Mode]] integration and aesthetic flexibility. (A transition from prior Neovim enthusiasm.)
- *Hyprland*: A dynamic tiling Wayland compositor offering extensive customization and smooth visuals, providing a BSPWM-like experience on Wayland.
- *Zsh*: The Z shell serves as my preferred interactive POSIX-compliant shell, augmented with various plugins and customizations for enhanced productivity. (Though alternatives like [[https://www.nushell.sh/][Nushell]] remain intriguing.)
- *Ghostty*: I use to switch from alacritty to kitty and back but ghostty has it all.
